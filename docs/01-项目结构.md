# 项目结构

## 概述

这是一个基于 React + Tauri + NestJS 的视觉小说游戏模板项目，采用 monorepo 架构，使用 pnpm workspace 进行包管理。

## 技术栈

### 前端 (apps/web)
- **框架**: React 19 + TypeScript
- **构建工具**: Vite
- **UI 库**: MUI Joy
- **状态管理**: Zustand
- **路由**: React Router
- **数据获取**: TanStack Query
- **动画**: Motion (Framer Motion)
- **游戏引擎**: Pixi'VN + Pixi'VN Ink
- **游戏框架**: NQTR (@drincs/nqtr)
- **样式**: Tailwind CSS
- **国际化**: i18next
- **桌面应用**: Tauri

### 后端 (apps/backend)
- **框架**: NestJS
- **数据库**: PostgreSQL
- **ORM**: Prisma
- **认证**: JWT (Passport)
- **文件存储**: 腾讯云 COS
- **API 文档**: Swagger

### 共享包 (packages/shared)
- **用途**: 前后端共享的类型定义和常量
- **构建**: TypeScript

## 关键配置文件

- `package.json`: 根项目配置，包含所有应用的脚本命令
- `pnpm-workspace.yaml`: 定义 monorepo 工作区
- `apps/backend/prisma/schema.prisma`: 数据库模型定义
- `apps/web/vite.config.ts`: Vite 构建配置
- `apps/desktop/src-tauri/tauri.conf.json`: Tauri 应用配置

## 开发命令

### 启动开发服务器
```bash
# 启动前端
pnpm dev:web

# 启动后端
pnpm dev:backend

# 启动桌面应用
pnpm dev:desktop
```

### 构建
```bash
# 构建所有应用
pnpm build

# 单独构建
pnpm build:web
pnpm build:backend
pnpm build:desktop
```
