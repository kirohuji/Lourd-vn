# 前后端设计

## 架构概览

本项目采用前后端分离架构，前端使用 React + Tauri，后端使用 NestJS，通过 RESTful API 进行通信。

```
┌─────────────────┐         ┌─────────────────┐
│   前端 (React)   │  HTTP   │   后端 (NestJS)  │
│                 │ ◄─────► │                 │
│  - Web App      │         │  - REST API     │
│  - Desktop App  │         │  - JWT Auth     │
│  (Tauri)        │         │  - Prisma ORM   │
└─────────────────┘         └─────────────────┘
                                      │
                                      ▼
                              ┌─────────────────┐
                              │   PostgreSQL    │
                              │    Database     │
                              └─────────────────┘
```

## 后端设计

### 技术架构

- **框架**: NestJS (基于 Express)
- **语言**: TypeScript
- **数据库**: PostgreSQL
- **ORM**: Prisma
- **认证**: JWT (Passport.js)
- **文件存储**: 腾讯云 COS (对象存储)

### 模块结构

#### 1. 认证模块 (auth)
- **功能**: 用户认证和授权
- **文件**:
  - `auth.controller.ts`: 认证相关 API 端点
  - `auth.service.ts`: 认证业务逻辑
  - `jwt.strategy.ts`: JWT 策略配置
  - `guards/`: 认证守卫
    - `jwt-auth.guard.ts`: JWT 认证守卫
    - `roles.guard.ts`: 角色权限守卫
  - `decorators/`: 装饰器
    - `current-user.decorator.ts`: 获取当前用户
    - `public.decorator.ts`: 公开路由标记
    - `roles.decorator.ts`: 角色权限装饰器

#### 2. 用户模块 (users)
- **功能**: 用户管理
- **文件**:
  - `users.controller.ts`: 用户相关 API
  - `users.service.ts`: 用户业务逻辑
  - `users.module.ts`: 用户模块定义

#### 3. 游戏配置模块 (game-config)
- **功能**: 游戏配置管理（地图、角色、房间等）
- **文件**:
  - `game-config.controller.ts`: 游戏配置 API
  - `game-config.service.ts`: 游戏配置业务逻辑
  - `game-config.module.ts`: 游戏配置模块定义

#### 4. 资源清单模块 (manifest)
- **功能**: 资源清单管理
- **文件**:
  - `manifest.controller.ts`: 资源清单 API
  - `manifest.service.ts`: 资源清单业务逻辑
  - `manifest.module.ts`: 资源清单模块定义

#### 5. 公共模块 (common)
- **Prisma 模块**: 数据库连接和 Prisma Client
- **COS 模块**: 腾讯云对象存储服务
- **工具函数**: 通用工具函数

### 数据库设计

#### 核心数据模型

1. **User (用户)**
   - `id`: 用户 ID
   - `email`: 邮箱（可选，用于管理员登录）
   - `password`: 密码哈希（仅用于管理员邮箱登录）
   - `wechatOpenId`: 微信 OpenID
   - `wechatUnionId`: 微信 UnionID
   - `role`: 用户角色 (USER | ADMIN)
   - `resources`: 关联的资源

2. **Resource (资源)**
   - `id`: 资源 ID
   - `alias`: 资源别名
   - `src`: 资源路径
   - `bundle`: 资源包名
   - `hash`: 文件哈希值（唯一）
   - `fileSize`: 文件大小
   - `fileType`: 文件类型
   - `mimeType`: MIME 类型
   - `cosKey`: 腾讯云 COS 键
   - `originalName`: 原始文件名
   - `uploaderId`: 上传者 ID

3. **ManifestBundle (资源清单包)**
   - `id`: 清单包 ID
   - `name`: 清单包名称（唯一）
   - `description`: 描述

4. **Map (地图)**
   - `id`: 地图 ID
   - `name`: 地图名称
   - `bundle`: 资源包
   - `backgroundType`: 背景类型
   - `backgroundJson`: 背景配置（JSON）
   - `locations`: 关联的位置
   - `rooms`: 关联的房间

5. **Location (位置)**
   - `id`: 位置 ID
   - `mapId`: 所属地图 ID
   - `name`: 位置名称
   - `iconAlias`: 图标别名
   - `order`: 排序
   - `rooms`: 关联的房间

6. **Room (房间)**
   - `id`: 房间 ID
   - `mapId`: 所属地图 ID（可选）
   - `locationId`: 所属位置 ID
   - `name`: 房间名称
   - `isEntrance`: 是否为入口
   - `backgroundType`: 背景类型
   - `backgroundJson`: 背景配置（JSON）
   - `hotspotsJson`: 热点配置（JSON）

7. **Character (角色)**
   - `id`: 角色 ID
   - `name`: 角色名称
   - `age`: 年龄
   - `icon`: 图标
   - `color`: 颜色
   - `enabled`: 是否启用
   - `order`: 排序

### API 设计

#### 认证相关
- `POST /auth/login`: 用户登录
- `POST /auth/register`: 用户注册
- `GET /auth/profile`: 获取当前用户信息

#### 用户相关
- `GET /users`: 获取用户列表（管理员）
- `GET /users/:id`: 获取用户详情
- `PUT /users/:id`: 更新用户信息
- `DELETE /users/:id`: 删除用户

#### 游戏配置相关
- `GET /game-config/maps`: 获取地图列表
- `POST /game-config/maps`: 创建地图
- `GET /game-config/characters`: 获取角色列表
- `POST /game-config/characters`: 创建角色

#### 资源相关
- `POST /resources/upload`: 上传资源
- `GET /resources`: 获取资源列表
- `DELETE /resources/:id`: 删除资源

## 前端设计

### 技术架构

- **框架**: React 19 + TypeScript
- **构建工具**: Vite
- **状态管理**: Zustand
- **数据获取**: TanStack Query
- **路由**: React Router
- **UI 库**: MUI Joy
- **游戏引擎**: Pixi'VN + NQTR

### 目录结构说明

#### 核心目录

1. **components/**: 可复用组件
   - `MenuButton.tsx`: 菜单按钮
   - `ChoiceButton.tsx`: 选择按钮
   - `ModalDialog.tsx`: 模态对话框
   - `GameSaveSlot.tsx`: 游戏存档槽
   - 等等...

2. **screens/**: 页面组件
   - `MainMenu.tsx`: 主菜单
   - `NarrationScreen.tsx`: 叙述屏幕
   - `GameSaveScreen.tsx`: 存档/读档屏幕
   - `Settings.tsx`: 设置页面
   - `admin/`: 管理后台页面
   - `nqtr/`: NQTR 相关页面（地图、时间、活动等）

3. **stores/**: Zustand 状态管理
   - `auth-store.ts`: 认证状态
   - `useInterfaceStore.ts`: 界面状态
   - `useSettingsScreenStore.ts`: 设置状态
   - `useGameSaveScreenStore.ts`: 存档状态
   - 等等...

4. **hooks/**: 自定义 Hooks
   - `useGameProps.ts`: 游戏属性
   - `useQueryInterface.ts`: 接口数据查询
   - `useNQTRDetector.tsx`: NQTR 检测
   - `useKeyboardDetector.ts`: 键盘检测
   - 等等...

5. **utils/**: 工具函数
   - `api-client.ts`: API 客户端
   - `save-utility.ts`: 存档工具
   - `ink-utility.ts`: Ink 脚本工具
   - `nqtr-utility.ts`: NQTR 工具
   - `auth-guard.tsx`: 路由守卫
   - 等等...

6. **values/**: 游戏数据配置
   - `characters.ts`: 角色定义
   - `locations.tsx`: 位置定义
   - `maps.tsx`: 地图定义
   - `rooms.tsx`: 房间定义
   - `activities.tsx`: 活动定义
   - `quests/`: 任务定义

7. **models/**: 数据模型
   - `Character.ts`: 角色模型
   - `GameSaveData.ts`: 存档数据模型
   - `nqtr/`: NQTR 相关模型
     - `Activity.ts`: 活动模型
     - `Location.ts`: 位置模型
     - `Map.ts`: 地图模型
     - `Quest.ts`: 任务模型
     - `Room.ts`: 房间模型

8. **labels/**: 标签系统
   - Ink 脚本标签定义
   - TypeScript 标签加载器

9. **services/**: 服务层
   - `gameConfigFactory.ts`: 游戏配置工厂

### 路由设计

#### 游戏路由
- `/`: 主菜单
- `/login`: 用户登录
- `/loading`: 加载页面
- `/narration`: 叙述页面（主要游戏界面）
- `/navigation`: 导航页面（NQTR 模式）
- `/map`: 地图页面

#### 管理后台路由
- `/admin/login`: 管理员登录
- `/admin/resources`: 资源管理
- `/admin/characters`: 角色管理
- `/admin/maps`: 地图管理
- `/admin/users`: 用户管理

### 状态管理

使用 Zustand 进行状态管理，主要状态包括：

1. **认证状态** (`auth-store.ts`)
   - 用户信息
   - 登录状态
   - Token

2. **界面状态** (`useInterfaceStore.ts`)
   - UI 显示/隐藏
   - 界面配置

3. **设置状态** (`useSettingsScreenStore.ts`)
   - 设置面板开关
   - 设置项

4. **存档状态** (`useGameSaveScreenStore.ts`)
   - 存档面板开关
   - 存档列表

5. **游戏状态** (多个 store)
   - 对话历史
   - 游戏进度
   - NQTR 状态

### 数据获取

使用 TanStack Query 进行数据获取和缓存：

- `useQueryInterface`: 获取接口数据
- `useQueryLastSave`: 获取最后存档
- `useQuerySaves`: 获取存档列表
- `useQueryNQTR`: 获取 NQTR 数据

### 游戏引擎集成

#### Pixi'VN
- 视觉小说引擎
- 处理对话、选择、背景、角色等

#### NQTR (@drincs/nqtr)
- 游戏框架
- 处理地图、房间、活动、任务等

#### Ink 脚本
- 叙事脚本语言
- 支持标签系统扩展功能

## 前后端通信

### API 客户端

前端使用 `utils/api-client.ts` 封装 API 请求：

- 自动添加 JWT Token
- 统一错误处理
- 请求/响应拦截

### 认证流程

1. 用户登录 → `POST /auth/login`
2. 后端返回 JWT Token
3. 前端存储 Token
4. 后续请求自动携带 Token
5. 后端验证 Token 并授权

### 数据同步

- 游戏配置数据从后端获取
- 资源文件从后端或 CDN 加载
- 用户数据存储在 IndexedDB（本地）和数据库（云端）

## 部署架构

### 前端部署
- **Web**: 静态文件部署到 CDN 或 Web 服务器
- **Desktop**: 打包为 Tauri 应用（Windows/macOS/Linux）
- **Mobile**: 打包为 Tauri 应用（Android/iOS）

### 后端部署
- NestJS 应用部署到服务器
- PostgreSQL 数据库
- 腾讯云 COS 存储资源文件

### 环境配置
- 开发环境: 本地开发服务器
- 生产环境: 生产服务器 + CDN
