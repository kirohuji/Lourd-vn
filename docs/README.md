## 项目概述

这是一个基于 React + Tauri + NestJS 的视觉小说游戏模板项目，采用 monorepo 架构。

### 主要特性

- 🎮 **视觉小说引擎**: 基于 Pixi'VN 的完整游戏引擎
- 🗺️ **NQTR 框架**: 地图、房间、活动、任务系统
- 💾 **存档系统**: 多存档槽位，自动存档
- 🎨 **现代化 UI**: MUI Joy + Tailwind CSS
- 📱 **跨平台**: Web、桌面（Tauri）、移动端支持
- 🔐 **用户系统**: JWT 认证，角色权限管理
- 📦 **资源管理**: 资源上传、清单管理
- 🌐 **国际化**: 多语言支持
- 📝 **Ink 脚本**: 支持 Ink 叙事脚本语言

### 技术栈

**前端**
- React 19 + TypeScript
- Vite
- MUI Joy
- Zustand
- TanStack Query
- Pixi'VN + NQTR
- Tauri

**后端**
- NestJS
- PostgreSQL
- Prisma
- JWT (Passport)
- 腾讯云 COS
