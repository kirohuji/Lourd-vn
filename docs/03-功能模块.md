# 功能模块

## 概述

本项目是一个视觉小说游戏模板，集成了 Pixi'VN 游戏引擎和 NQTR 游戏框架，提供了完整的游戏开发基础设施。

## 核心功能模块

### 1. 用户认证与授权

#### 功能描述
- 支持多种登录方式（邮箱密码、微信）
- 用户角色管理（普通用户、管理员）
- JWT Token 认证
- 路由守卫保护

#### 实现位置
- **后端**: `apps/backend/src/modules/auth/`
- **前端**: `apps/web/src/stores/auth-store.ts`, `apps/web/src/utils/auth-guard.tsx`

#### 主要功能
- 用户登录/注册
- Token 刷新
- 权限验证
- 路由保护

---

### 2. 游戏核心系统

#### 2.1 视觉小说系统 (Pixi'VN)

**功能描述**
- 对话系统
- 角色显示
- 背景切换
- 选择分支
- 存档/读档

**实现位置**
- `apps/web/src/screens/NarrationScreen.tsx`
- `apps/web/src/hooks/useNarrationFunctions.ts`
- `apps/web/src/stores/useDialogueCardStore.ts`

**主要功能**
- 对话文本显示（支持打字机效果）
- 角色头像显示
- 背景图片切换
- 选择项显示
- 历史记录查看
- 自动播放
- 跳过对话

#### 2.2 NQTR 游戏框架

**功能描述**
- 地图系统
- 房间系统
- 活动系统
- 任务系统
- 时间系统

**实现位置**
- `apps/web/src/screens/nqtr/`
- `apps/web/src/values/` (游戏数据配置)
- `apps/web/src/models/nqtr/`

**主要功能**

1. **地图系统** (`MapScreen.tsx`)
   - 地图显示
   - 位置导航
   - 房间入口

2. **房间系统** (`QuickRooms.tsx`)
   - 房间列表
   - 房间切换
   - 热点交互

3. **活动系统** (`QuickActivities.tsx`)
   - 活动列表
   - 活动执行
   - 活动效果

4. **任务系统** (`quests/`)
   - 任务定义
   - 任务进度
   - 任务完成

5. **时间系统** (`TimeScreen.tsx`)
   - 时间显示
   - 时间段切换（早晨、下午、晚上、夜晚）
   - 时间相关背景切换

6. **备忘录系统** (`MemoScreen.tsx`)
   - 游戏内备忘录
   - 信息记录

## 数据流

### 游戏数据流

```
用户操作
  ↓
React 组件
  ↓
Zustand Store / TanStack Query
  ↓
Pixi'VN / NQTR 引擎
  ↓
游戏状态更新
  ↓
UI 渲染
```

### API 数据流

```
前端组件
  ↓
TanStack Query Hook
  ↓
API Client (utils/api-client.ts)
  ↓
后端 API (NestJS)
  ↓
Prisma ORM
  ↓
PostgreSQL 数据库
```

## 开发建议

### 添加新功能模块

1. **前端模块**
   - 在 `screens/` 创建新页面
   - 在 `stores/` 创建状态管理（如需要）
   - 在 `hooks/` 创建自定义 Hook（如需要）
   - 在 `utils/` 创建工具函数（如需要）

2. **后端模块**
   - 在 `modules/` 创建新模块
   - 定义 Controller、Service、Module
   - 更新 `app.module.ts`

3. **数据模型**
   - 在 `prisma/schema.prisma` 定义模型
   - 运行迁移: `pnpm prisma:migrate`
   - 更新共享类型（如需要）

### 添加新游戏内容

1. **角色**: 在 `values/characters.ts` 定义
2. **地图**: 在 `values/maps.tsx` 定义
3. **位置**: 在 `values/locations.tsx` 定义
4. **房间**: 在 `values/rooms.tsx` 定义
5. **活动**: 在 `values/activities.tsx` 定义
6. **任务**: 在 `values/quests/` 定义
7. **Ink 脚本**: 在 `ink/` 或 `script-package/ink/` 创建

## 性能优化

1. **代码分割**: 使用 React.lazy 和 Suspense
2. **资源懒加载**: 图片和资源按需加载
3. **状态优化**: 使用 Zustand 的 selector 避免不必要的重渲染
4. **查询缓存**: 使用 TanStack Query 的缓存机制
5. **打包优化**: Vite 的代码分割和压缩
