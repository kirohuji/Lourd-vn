# 优化图片预览和批量移动功能

## 1. 优化 Prompt 显示格式

### 1.1 修改后端 API，返回完整的 Prompt 信息

- **文件**: `apps/backend/src/modules/prompts/prompts.service.ts`
- 修改 `findImagesByCharacterPromptId` 和 `findImagesGrouped` 方法
- 在返回 `PromptImageResponseDto` 时，包含关联的 BasePrompt 和 CharacterPrompt 的详细信息：
  - BasePrompt: `basicPrompt`, `undesiredContent`
  - CharacterPrompt: `basicPrompt`, `undesiredContent`
- 修改 `PromptImageResponseDto` 类型定义（`packages/shared/src/types/prompt.ts`）：
  - 添加可选字段 `basePrompt?: { basicPrompt: string; undesiredContent?: string }`
  - 添加可选字段 `characterPrompt?: { basicPrompt: string; undesiredContent?: string }`

### 1.2 优化前端预览显示

- **文件**: `apps/admin/src/components/features/prompt-image-preview.tsx`
- 修改预览对话框中的 Prompt 显示部分
- 按组显示：
  - **Base Prompt 组**：显示 `basicPrompt` 和 `undesiredContent`（如果有）
  - **Character Prompt 组**：如果存在，显示 `basicPrompt` 和 `undesiredContent`（如果有）
- 使用清晰的视觉分组（卡片或分隔线）

## 2. 实现多选图片批量移动

### 2.1 添加多选状态管理

- **文件**: `apps/admin/src/pages/prompts.tsx`
- 添加状态：
  - `selectedImages: Set<number>` - 存储选中的图片 ID
  - `isSelectionMode: boolean` - 是否处于选择模式
- 添加切换选择模式的函数

### 2.2 实现复选框多选 UI

- **文件**: `apps/admin/src/components/features/prompt-image-preview.tsx`
- 修改组件，添加 `isSelected` 和 `onToggleSelect` props
- 在图片左上角显示复选框（仅在选择模式下显示）
- 选中状态的视觉反馈（边框高亮或背景色）

### 2.3 添加批量操作工具栏

- **文件**: `apps/admin/src/pages/prompts.tsx`
- 当有图片被选中时，显示浮动工具栏：
  - 显示选中数量
  - "移动到变体" 按钮
  - "取消选择" 按钮
- 工具栏位置：固定在底部或顶部

### 2.4 实现批量移动功能

- **文件**: `apps/admin/src/pages/prompts.tsx`
- 修改 `handleConfirmMoveImage` 函数，支持批量移动
- 使用 `Promise.all` 批量调用 `updateImageVariant`
- 显示批量操作进度和结果

### 2.5 修改移动对话框

- **文件**: `apps/admin/src/pages/prompts.tsx`
- 修改移动对话框，支持显示批量移动的图片数量
- 默认选择"未分类"
- 选择变体后立即执行移动（不需要确认按钮）

## 3. 移除单个移动按钮

### 3.1 移除 Move 按钮

- **文件**: `apps/admin/src/components/features/prompt-image-preview.tsx`
- 移除 `onMove` prop 和相关的 Move 按钮
- 保留删除按钮

### 3.2 添加选择模式切换按钮

- **文件**: `apps/admin/src/pages/prompts.tsx`
- 在图片集合标题栏添加"选择"按钮
- 点击后进入选择模式，显示复选框
- 再次点击退出选择模式

## 4. 数据流

```
用户操作流程：
1. 点击"选择"按钮 → 进入选择模式
2. 勾选多个图片 → 显示批量操作工具栏
3. 点击"移动到变体" → 打开移动对话框（默认"未分类"）
4. 选择目标变体 → 自动执行批量移动
5. 显示操作结果 → 清空选择，退出选择模式
```

## 5. 技术细节

- 使用 `Set<number>` 管理选中的图片 ID，提高查找效率
- 批量操作时显示加载状态
- 操作完成后自动刷新图片列表
- 保持响应式设计，工具栏在小屏幕上也能正常显示
