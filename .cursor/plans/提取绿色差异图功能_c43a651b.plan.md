# 提取绿色差异图功能

## 需求分析

用户希望从差异图中提取绿色差异部分，生成一张新图：

- 保持原图的宽高和位置信息
- 只显示绿色差异的像素
- 其他区域使用透明背景
- 支持下载提取的图片

## 实现方案

### 1. 添加提取绿色差异的工具函数

**文件**: `apps/admin/src/lib/utils/image-compare.ts`

添加新函数 `extractColorDiff`：

- 接收差异图的 ImageData 和要提取的颜色（RGB 值）
- 遍历所有像素，只保留匹配颜色的像素
- 其他像素设置为透明（alpha = 0）
- 返回新的 ImageData

**实现逻辑**：

```typescript
export function extractColorDiff(
    diffImageData: ImageData,
    targetColor: [number, number, number], // RGB 值，如 [0, 255, 0] 表示绿色
    tolerance?: number, // 颜色容差，默认 0（精确匹配）
): ImageData {
    const { width, height, data } = diffImageData;
    const result = new Uint8ClampedArray(width * height * 4);
    
    for (let i = 0; i < data.length; i += 4) {
        const r = data[i];
        const g = data[i + 1];
        const b = data[i + 2];
        const a = data[i + 3];
        
        // 检查是否匹配目标颜色（考虑容差）
        const match = Math.abs(r - targetColor[0]) <= (tolerance ?? 0) &&
                     Math.abs(g - targetColor[1]) <= (tolerance ?? 0) &&
                     Math.abs(b - targetColor[2]) <= (tolerance ?? 0);
        
        if (match) {
            // 保留原像素（包括 alpha）
            result[i] = r;
            result[i + 1] = g;
            result[i + 2] = b;
            result[i + 3] = a;
        } else {
            // 设置为透明
            result[i] = 0;
            result[i + 1] = 0;
            result[i + 2] = 0;
            result[i + 3] = 0;
        }
    }
    
    return new ImageData(result, width, height);
}
```

### 2. 添加下载图片的工具函数

**文件**: `apps/admin/src/lib/utils/image-compare.ts`

添加新函数 `downloadImageData`：

- 接收 ImageData 和文件名
- 将 ImageData 转换为 Canvas
- 转换为 Blob
- 创建下载链接并触发下载

**实现逻辑**：

```typescript
export function downloadImageData(
    imageData: ImageData,
    filename: string = 'image.png',
): void {
    const canvas = document.createElement('canvas');
    canvas.width = imageData.width;
    canvas.height = imageData.height;
    const ctx = canvas.getContext('2d');
    if (!ctx) {
        throw new Error('Failed to get canvas context');
    }
    ctx.putImageData(imageData, 0, 0);
    
    canvas.toBlob((blob) => {
        if (!blob) return;
        const url = URL.createObjectURL(blob);
        const a = document.createElement('a');
        a.href = url;
        a.download = filename;
        document.body.appendChild(a);
        a.click();
        document.body.removeChild(a);
        URL.revokeObjectURL(url);
    });
}
```

## 实现细节

### 颜色匹配逻辑

由于像素值可能有轻微变化，可以考虑：

- 精确匹配：`r === 0 && g === 255 && b === 0`
- 容差匹配：允许 ±5 的容差，避免因压缩等原因导致的颜色偏差

### 下载功能

- 文件名格式：`green-diff-${timestamp}.png`
- 使用 PNG 格式以支持透明背景

### UI 交互流程

1. 用户上传两张图片
2. 自动执行比较，显示差异图
3. 点击"提取绿色差异"按钮
4. 生成并显示提取的绿色差异图
5. 点击下载按钮保存图片

## 技术要点

1. **颜色提取**：遍历 ImageData 的每个像素，检查 RGB 值是否匹配目标颜色
2. **透明处理**：不匹配的像素设置为 `rgba(0, 0, 0, 0)`
3. **下载功能**：使用 Canvas API 和 Blob API 实现客户端下载
4. **性能考虑**：大图片的像素遍历可能较慢，可以考虑使用 Web Worker（可选优化）
