# 添加加载状态和进度条

## 概述

在 `LoadingScreen` 和 `game-initialization.ts` 中添加详细的加载状态提示和进度条，按照用户指定的流程显示每个步骤的进度。

## 实现方案

### 1. 修改 `game-initialization.ts`

- 为 `initializeGame` 函数添加一个可选的进度回调参数 `onProgress?: (status: string, progress: number) => void`
- 调整步骤顺序和显示文本，按照用户指定的流程：
- 步骤 1: "正在加载核心资源…" (0% → 25%) - 对应 `import('../values'), import('../labels')` 和 `defineAssets()`
- 步骤 2: "正在准备角色与立绘…" (25% → 45%) - 对应 `loadCharactersFromAPI()`
- 步骤 3: "正在初始化场景与背景…" (45% → 65%) - 对应 `defineAssets()` 中的场景资源加载（如果已加载则跳过）
- 步骤 4: "正在载入剧情数据…" (65% → 85%) - 对应 `importAllInkLabels()`
- 步骤 5: "正在校验存档信息…" (85% → 100%) - 对应 `initializeIndexedDB()`
- 完成: "初始化完毕，正在进入故事世界…" (100%)

### 2. 修改 `LoadingScreen.tsx`

- 添加 `progress` 状态（0-100）
- 将 `setLoadingStatus` 和进度更新传递给 `initializeGame`
- 使用 MUI Joy 的 `LinearProgress` 组件显示进度条
- 在 `CircularProgress` 下方显示进度条和百分比文本
- 显示格式：状态文本 + 进度条 + 百分比（如 "45%"）

## 文件修改

### [apps/web/src/utils/game-initialization.ts](apps/web/src/utils/game-initialization.ts)

- 添加 `onProgress` 回调参数
- 重新组织步骤顺序以匹配用户指定的流程
- 在每个步骤调用回调更新状态和进度
- 将 `initI18n()` 合并到其他步骤中（不单独显示）

### [apps/web/src/screens/LoadingScreen.tsx](apps/web/src/screens/LoadingScreen.tsx)

- 添加 `progress` 状态（初始值为 0）
- 导入 `LinearProgress` 组件
- 创建进度回调函数传递给 `initializeGame`
- 更新 UI 布局：
- 保留 `CircularProgress` 作为视觉指示器
- 添加 `LinearProgress` 显示进度条
- 显示状态文本和百分比

## 进度分配

- 步骤 1: 0% → 25% (25%)
- 步骤 2: 25% → 45% (20%)
- 步骤 3: 45% → 65% (20%)
- 步骤 4: 65% → 85% (20%)
- 步骤 5: 85% → 100% (15%)
- 总计: 100%
