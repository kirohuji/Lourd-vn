# 修复变体管理和图片删除功能

## 问题分析

1. **变体列表名称编辑**：`prompt-variant-manager.tsx` 中变体列表只显示名称，无法编辑
2. **上传图片时变体列表获取**：`prompt-image-upload.tsx` 中变体列表获取逻辑需要确认
3. **删除图片后刷新**：`prompts.tsx` 中删除图片后未调用 `refetchImages()`
4. **多选删除**：需要支持批量删除选中的图片

## 修复方案

### 1. 添加变体名称编辑功能

**文件**: `apps/admin/src/components/features/prompt-variant-manager.tsx`

- 在变体列表项中添加编辑按钮（或双击编辑）
- 添加编辑状态管理（`editingVariantId`, `editingVariantName`）
- 实现内联编辑：点击变体名称时进入编辑模式，显示 `Input` 组件
- 保存时调用 `updateMutation.mutateAsync` 更新变体名称
- 支持 `Enter` 保存、`Escape` 取消

**修改位置**:

- 第 207-244 行：变体列表渲染部分
- 添加编辑相关的状态和处理函数

### 2. 确认并修复上传图片时的变体列表获取

**文件**: `apps/admin/src/components/features/prompt-image-upload.tsx`

- 检查第 45-48 行的 `usePromptVariants` 调用
- 确认参数逻辑：当 `characterPromptId` 存在时传递 `characterPromptId`，否则传递 `basePromptId`
- 如果 `characterPromptId` 为 0，应该视为不存在

**修改位置**:

- 第 45-48 行：`usePromptVariants` 调用

### 3. 修复删除图片后刷新

**文件**: `apps/admin/src/pages/prompts.tsx`

- 在 `handleConfirmDelete` 函数中，删除图片成功后调用 `refetchImages()`
- 确保删除后图片列表及时更新

**修改位置**:

- 第 238-241 行：删除图片的逻辑

### 4. 实现多选删除功能

**文件**: `apps/admin/src/pages/prompts.tsx`

- 在批量操作工具栏中添加"删除选中"按钮
- 添加 `handleBatchDelete` 函数，遍历 `selectedImages` 执行批量删除
- 使用 `Promise.all` 并行删除所有选中的图片
- 删除成功后调用 `refetchImages()` 并清空选择状态
- 删除前显示确认对话框，显示要删除的图片数量

**修改位置**:

- 第 447-450 行：批量操作工具栏
- 添加 `handleBatchDelete` 函数
- 修改删除确认对话框以支持批量删除

## 实现细节

### 变体名称编辑 UI

```typescript
// 在变体列表项中
{editingVariantId === variant.id ? (
  <Input
    value={editingVariantName}
    onChange={(e) => setEditingVariantName(e.target.value)}
    onKeyDown={(e) => {
      if (e.key === 'Enter') handleSaveVariantName(variant.id);
      if (e.key === 'Escape') setEditingVariantId(null);
    }}
    onBlur={() => handleSaveVariantName(variant.id)}
    autoFocus
  />
) : (
  <span 
    className='text-sm font-medium cursor-pointer'
    onClick={() => {
      setEditingVariantId(variant.id);
      setEditingVariantName(variant.name);
    }}
  >
    {variant.name}
  </span>
)}
```

### 批量删除逻辑

```typescript
const handleBatchDelete = () => {
  if (selectedImages.size === 0) return;
  setDeleteType('image');
  setItemToDelete({ id: Array.from(selectedImages)[0], count: selectedImages.size });
  setDeleteConfirmOpen(true);
};

// 在 handleConfirmDelete 中
if (deleteType === 'image' && itemToDelete?.count && itemToDelete.count > 1) {
  // 批量删除
  await Promise.all(
    Array.from(selectedImages).map(id => deleteImage.mutateAsync(id))
  );
  setSelectedImages(new Set());
  setIsSelectionMode(false);
  refetchImages();
}
```
